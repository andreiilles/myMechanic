# myMechanic - Car Maintenance Tracker

> A modern Flutter application for managing vehicle maintenance, service history, and reminders.

## 📱 About

myMechanic is a comprehensive car maintenance tracking application built with Flutter and Supabase. It helps users manage their vehicles, track maintenance activities, and never miss important service appointments.

```bash

# Install dependencies
flutter pub get

# Run the app
flutter run
```

## 🏗️ Architecture

- **Frontend**: Flutter (Dart)
- **Backend**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Storage**: Supabase Storage
- **State Management**: Provider

## ✨ Key Features

- 🔐 User authentication and role-based access
- 🚗 Multiple vehicle management
- 🔧 Maintenance record tracking
- 📅 Service reminders and notifications
- 📊 Service history and analytics
- 📸 Image upload for vehicles and records
- 🤝 Vehicle sharing capabilities
